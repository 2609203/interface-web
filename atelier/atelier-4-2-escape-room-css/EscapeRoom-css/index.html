Bienvenue dans l'Escape Room DevTools

Bienvenue dans cette aventure interactive ! Vous allez apprendre à maîtriser les outils de développement du navigateur.

Objectif: Résolvez 10 énigmes en utilisant les DevTools pour progresser

Outils nécessaires :

  • F12 ou Clic droit → Inspecter
  • Onglet Elements pour voir le HTML
  • Panel Styles pour modifier le CSS
  • Un peu de curiosité et de logique !

Règles du jeu :

  • Chaque salle contient une énigme à résoudre
  • Utilisez uniquement les DevTools (pas d'édition de fichiers)
  • Lisez attentivement les indices
  • Attention aux fausses pistes !

Aide générale

Raccourcis utiles :

  • F12 : Ouvrir/fermer les DevTools
  • Ctrl+Shift+C : Mode sélection d'élément
  • Double-clic sur une valeur CSS pour la modifier
  • Clic droit sur un élément → Edit as HTML
