Exercice 1 — Flexbox

Consignes

  • Faire une entête avec le logo/titre à gauche et un menu à droite (sur une seule ligne).
  • Dans <main>, afficher 3 cartes sur une ligne, qui passent sur plusieurs lignes si l’écran est étroit.
  • Garder un espacement régulier entre les éléments.
  • Le pied de page est centré.
fichier: flex.html

Exercice 2 — Grid

Consignes

  • Construire un gabarit de page avec Grid et zones nommées :
    • entete en haut,
    • aside (menu latéral) à gauche,
    • contenu au centre,
    • extra (infos) à droite,
    • pied en bas.
  • Bureau : 3 colonnes (200px / 1fr / 200px).
  • Mobile : une seule colonne (les zones l’une sous l’autre).
fichier: grid.html
