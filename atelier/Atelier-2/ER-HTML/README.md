# Escape Room HTML — Thème pirates

Inspectez le code HTML, corrigez les erreurs et progressez à travers les trois salles.

## Objectifs

- reconnaître les éléments sémantiques HTML5;
- vérifier la structure d'un formulaire;
- distinguer différents types de champs;
- associer correctement les libellés et les champs;
- utiliser les outils de développement du navigateur.

## Pour commencer

1. Extrayez complètement le fichier ZIP.
2. Ouvrez `index.html` dans votre navigateur.
3. Appuyez sur `F12`, ou utilisez **Inspecter**, pour ouvrir les outils de développement.
4. Suivez les consignes affichées dans chaque salle.
5. Inspectez le HTML et les commentaires, puis apportez les corrections demandées.

L'activité fonctionne directement dans le navigateur. Il n'est pas nécessaire d'installer les dépendances npm ni de démarrer Vite.

## Règles

- Modifiez seulement ce qui est nécessaire pour corriger les erreurs HTML.
- Conservez les fichiers CSS et JavaScript fournis.
- Utilisez l'inspecteur, la console et le validateur HTML pour vérifier votre travail.
- Enregistrez régulièrement vos modifications.

Vous pouvez valider vos pages avec le [validateur HTML du W3C](https://validator.w3.org/).

## Solutionnaire

Essayez d'abord de corriger la salle par vous-même. Si vous êtes bloqué ou souhaitez vérifier votre travail, consultez `solutionnaire/CORRIGE.md`.
